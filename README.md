# Integrated services

This directory is the integration boundary for the single Railway service.

- `openrouter`: model routing
- `exa`: research/discovery
- `firecrawl`: crawl/scrape/extraction
- `discord`: primary channel
- `github`: repository automation
- `notion`: documentation
- `supabase`: data
- `linear`: project tracking
- `slack`: optional bridge
- `wix`: site/business automation

The service should use the official APIs/connectors for these systems. Credentials are supplied through Railway Variables, never committed here.
